# Security and private data

Report suspected security issues privately to **office@installateur1210.at**
with subject `Agent Service Exchange security report`.

Include the affected endpoint, reproduction with synthetic data and likely
impact. Do not publish customer data, credentials or working exploit details in
a public issue. Do not test submissions against production or purchase contacts.

The public demo is restricted to the isolated review endpoint. It cannot send
mail or make payments. Hosted-service privacy and retention information:
https://api.eucompliance.tools/exchange/privacy

There is currently no paid bug-bounty programme or guaranteed response time.
